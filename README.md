# Champions Arena — Sports Club Landing Page

A responsive landing page for a fictional hockey club and sports complex, built with **Tailwind CSS** and **DaisyUI** components.

## Sections

- **Navbar** with a *Get Tickets* call to action
- **Hero carousel** (DaisyUI) introducing the club's players
- **About the club:** player facilities, experienced coaches, senior players and training grounds
- **Programs:** Junior, Teenager and Professional tracks with registration buttons
- **Merchandise:** a product card for the club jersey with rating, price and delivery info
- **FAQ accordion:** gear, training, private lessons, bookings and pricing
- **Get in touch:** phone, email and location, plus a feedback form
- **Footer** with navigation and social links

## Tech Stack

| Layer | Technology |
| --- | --- |
| Markup | HTML5 |
| Styling | Tailwind CSS (Play CDN), DaisyUI 4 (carousel, collapse, cards, buttons) |
| Typography | Google Fonts (Manrope) |
| Hosting | GitHub Pages |
